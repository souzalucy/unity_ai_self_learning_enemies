# RPG Minigame — "Arena Brawl"

Survive escalating waves of melee enemies in a pillared arena, or defeat them all before your
HP runs out.

## Build it

1. `Tools → Self-Learning Enemies → Minigames → Build RPG Arena Scene`
2. Bake a NavMesh (Window → AI → Navigation → Bake).
3. Press Play.

The arena (pillars tagged `Cover`) is generated by `RPGArenaBuilder`; the player and enemies are
composed at runtime by `MinigameComposer`.

## Composition (matches `CreateRPGDefaults()`: obs 28, discrete [6], continuous 2)

| Layer  | Component(s)                                                              |
|--------|---------------------------------------------------------------------------|
| Brain  | `EnemyBrain` + `GenreProfile(RPG)` + `BehaviorParameters` + `DecisionRequester` |
| Obs    | `ObsSelfTransform` (7) + `ObsTargetTransform` (8) + `ObsSelfStatus` (5) + `ObsGridSensor` 2×2×2 tags (8) = 28 |
| Action | `ActionNavMeshMovement` (2 cont) + `ActionCombat` (1 branch `[6]`)         |
| Reward | `RewardCombatPerformance` + `RewardSurvival` + `RewardDistanceManagement`  |

`ActionCombat` slots: `none, attack1, attack2, defend, heal, flee` (the heal slot self-heals via
`EnemyWiring`; defend/flee deal 0 damage and are movement-adjacent behaviours).

## Event wiring (done for you by `EnemyWiring`)

- `ActionCombat.OnAttackExecuted(dmg)` → `RewardCombatPerformance.RegisterHit(dmg)`
- `SimpleStatusProvider.OnDeath` → `EnemyBrain.ReportDeath()` (death penalty) + notify manager
- Player dies → surviving enemies get `EnemyBrain.ReportObjectiveComplete()` (objective reward)

## Play

- **Move** WASD, **look** mouse, **fire** LMB, **heal** E.
- Heuristic mode: hand an enemy to the AI's key bindings (WASD / Space / E / Q).

## Train

```bash
mlagents-learn rpg_trainer_config.yaml --run-id=RPG_01
```
